# 维护与清理

## 迁移与普通整理

沿用 README 中已确定的类型和目录；仅类型或长期职责变化时调整结构，不因某轮未使用或暂时为空删除本项目约定需要的目录。先判断文件用途、引用、已有改动和本次范围，说明必要的路径映射后执行。按职责归并重复的汇报、运行结果或代码工具位置；已有固定路径没有迁移需求就沿用，不为套用示例名称而迁移。

移动不覆盖独有内容。同步当前代码、配置、README 和状态中的引用，验证受影响入口/链接；历史讨论与冻结版本保留原路径含义，在本轮记录迁移关系即可。目录整理不顺带执行生产更新、全量重算或业务重写。

删除只针对本轮确认无用的临时文件、已不被使用的重复产物或按既定保留规则淘汰的内容。保留原始资料、输入、有效测试、讨论、冻结版本和必要结果证据。年龄、名称、Git 未跟踪或可再生成都不能单独证明可删；用途不明时留存并说明。

## 临时区边界

- `.tmp/work/<task-id>/`：活跃或用途未明的内容，清理脚本不处理。
- `.tmp/disposable/`：用途结束、必要证据已保存且明确可丢弃的内容，等待手动清理；任何运行任务都不能再依赖它。

收尾保存必要证据，已确认无用的内容可归入 disposable，但不默认删除。不把整个 work 当垃圾；有价值的失败证据提升到 outputs/runs。无内容不建临时目录。

递归移动/删除前核实解析后的绝对路径仍在本项目及指定范围；Windows 使用同一 shell 的原生文件命令或专用 Python 脚本，不跨 shell 拼接，不运行全项目 git clean -fdx。

## 手动清理

不配置定时清理。用户提出清理请求后，由 AI 执行，或用户自行运行以下命令；已有明确请求无需再次确认。

填入真实项目路径和可用 Python 解释器的绝对路径，含空格的参数加引号：

```text
"<Python绝对路径>" -X utf8 "<项目绝对路径>/skills/project-manager/scripts/clean_temp.py" --root "<项目绝对路径>"
```

脚本只处理 .tmp/disposable，不按年龄或 Git 未跟踪扩大范围；若用户要求整理其他临时内容，先确认用途并保存证据，再按本次请求处理。目标不存在或为空时无需创建；完成后简报范围及实际结果，失败说明已完成范围，不绕过错误强删。

## 隐藏与记录

点号目录保留原路径；Windows 在原属性上增加 Hidden，不清除其他属性或改全局显示。点号前缀不代表垃圾，.git、工具索引、环境和 state 不能按临时文件删。

普通整理记入本轮讨论及报告，无需另设清理台账。单独清理临时文件只回复结果，不另造业务讨论、HTML 或 Git 提交。
